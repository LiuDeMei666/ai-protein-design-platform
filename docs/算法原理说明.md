# AI 辅助蛋白设计平台 · 算法原理说明

本文说明平台每一项输出的**算法来源、计算方式与适用边界**。
编写原则是：**任何数字都必须能追溯到具体的算法或已发表结论，不允许黑箱**。

---

## 一、总体设计哲学

在**没有企业标注数据**的前提下，平台采用三重叠加策略：

```
ESM-2 蛋白语言模型零样本打分（无需训练，提供序列层面的"自然度"信号）
        +
确定性生物物理计算（完全可复现，提供无争议的基线）
        +
领域规则约束（把胶原/蛋白酶/蛋白A 的领域知识编码为可配置规则）
        =
开箱即用且结果可解释的预测
```

**明确不做什么**：
* 不拟合没有数据支撑的黑箱模型；
* 不把 0-100 的评分伪装成 ΔΔG（kcal/mol）这类绝对物理量；
* 不在超长序列上静默截断；
* 不在缺数据时悄悄给一个"看起来合理"的数字。

## 二、序列层：校验与清洗

| 步骤 | 规则 |
| --- | --- |
| 清洗 | 移除空白、换行、数字、`*`、`-`、`.`、`|` |
| 合法 | 20 种标准氨基酸（ACDEFGHIKLMNPQRSTVWY） |
| 歧义 | `B`(Asn\|Asp) `Z`(Gln\|Glu) `J`(Leu\|Ile) `X`(任意) `U`(硒代半胱氨酸) `O`(吡咯赖氨酸) |
| 长度 | 默认上限 5000 aa（可配置） |

**分级策略**：
* **宽松模式**（性质预测）：歧义残基产生警告，预测继续，相关指标置信度下降；
* **严格模式**（突变设计）：歧义残基**报错**；被清理的非空白字符（数字、`*` 等）
  也**报错**而非警告——突变设计入口绝不能容忍脏输入。

## 三、结构预测层

### 3.1 可插拔 Provider

| Provider | 类型 | 长度上限 | 说明 |
| --- | --- | --- | --- |
| `esmatlas` | 在线 REST | 400 aa | 主通道。实测 72 aa ≈ 2.3 s；382 aa ≈ 183 s |
| `local_esmfold` | 本地推理 | 1024 aa | 离线后备，需 `fair-esm` + `openfold` |
| `stub` | 本地生成 | 无 | 理想 α-螺旋骨架，pLDDT 刻意压低到 30-45 |

降级链：`auto` 模式下按 `esmatlas → local_esmfold → stub` 顺序尝试，
**任何降级都写入 `degradation_reason` 并显示在界面与报告中**。

### 3.2 长序列域切分

切点优先级（从高到低）：
1. 低复杂度边界（单一残基占比 > 50% 的区域端点）
2. 胶原三股螺旋中断点（Gly-X-Y 相位被破坏处）
3. 柔性连接区（Gly/Ser/Pro/Thr/Gln 富集的 12 残基窗口）
4. 固定长度兜底

切点搜索范围限制在 `[start + 0.55×max_len, end]`，避免产生过短片段。
合并时把片段 PDB 重编号为全长坐标，并把**片段边界写入结果**。

> **必须理解**：片段间的相对空间取向**未经建模**。因此跨片段的接触、
> 整体构象不可信；片段内部的二级结构与置信度仍然有效。

### 3.3 pLDDT 量纲归一化

**实测差异**：ESM Atlas 在线接口返回的 B-factor 是 **0-1 的分数**（如 0.54~0.96），
而本地 ESMFold 与 AlphaFold 输出 0-100。

平台按"最大值 ≤ 1.5 即判定为分数制"自动归一化，判定结果写入 `stats.plddt_scale`。
若不归一化，会把 0.93 当作"0.93 分"的荒谬置信度。

### 3.4 结构分析算法

| 指标 | 算法 |
| --- | --- |
| SASA | **Shrake-Rupley** 数值积分（92 点黄金螺旋球面采样，探针 1.4 Å），用 `cKDTree` 加速邻居查询 |
| 相对 SASA | 实测 SASA / Tien et al. (2013) 理论最大值 |
| 二级结构 | **DSSP-lite**：按 Kabsch-Sander 氢键能量判据（E = 0.084·332·(1/r_ON + 1/r_CH − 1/r_OH − 1/r_CN)，阈值 −0.5 kcal/mol），识别 i→i+3/4/5 转角与 β 桥 |
| 接触图 | CA-CA 距离 < 8 Å |
| 回旋半径 | CA 坐标到质心的均方根距离 |
| 疏水核心暴露 | 疏水残基中相对 SASA > 0.25 的比例 |

> **DSSP-lite 的方向约定极易写错**：DSSP 的 n-turn 定义是"**CO(i)···HN(i+n)**"，
> 即**给体在 i+n、受体在 i**。早期实现方向写反会导致整条序列被判为无规卷曲。

## 四、蛋白语言模型层（ESM-2）

### 4.1 模型与推理配置

* 主模型：`facebook/esm2_t33_650M_UR50D`（33 层，隐层 1280）
* CPU 降级：`facebook/esm2_t12_35M_UR50D`
* 精度：V100 上 fp16（`torch.autocast`）
* 三级降级：主模型 GPU → 小模型 GPU → 小模型 CPU

### 4.2 零样本突变打分（核心）

**掩码边缘似然比**：

```
ΔlogP(a → b) = logP(b | context\{a}) − logP(a | context\{a})
```

其中 `context\{a}` 表示把位置 `a` 掩码后的上下文。
该值越大表示模型越"认可"这个替换，是稳定性/功能影响的**零样本代理**。

**实现关键**：对 L 个位点做 L 次掩码前向，按批大小（默认 8）分组一次性前向，
因此总代价约为 `L / batch_size` 次前向而非 L 次。

**归一化**：线性映射到 0-100，配置项 `design.zero_shot.delta_worst`（默认 −7.0，
实测有害突变的典型 ΔlogP 下界）与 `delta_best`（默认 0.0）。

### 4.3 序列自然度（**易错点**）

自然度 = 野生型残基在**掩码条件**下的平均对数概率（伪对数似然）。

> **为什么必须用掩码版本**：ESM-2 是双向编码器，位置 i 的输出表征通过自注意力
> **能看到残基 i 自己**。若直接取未掩码 logits 计算"预测自己"的概率，
> 结果会接近 0（实测某天然蛋白为 −0.157），**完全失去区分度**——模型只是在抄答案。
>
> 正确做法是把每个位置掩掉后读取该位点的对数概率。天然蛋白通常落在
> **−3 ~ −1** 区间，实测枯草杆菌蛋白酶 BPN' 为 **−1.08**。

### 4.4 超长序列的窗口处理

ESM-2 位置上限 1024（预留 `<cls>`/`<eos>`，实际可用 1022）。

* 嵌入：50% 重叠滑窗，重叠区取平均；
* 打分层：位点分配到以其为中心的上下文窗口（`start = clamp(pos − 511, 0, L−1022)`）。

## 五、性质预测层（9 项指标）

统一约定：**0-100 分，越高越好**（风险类指标为"安全性得分"）。
每项指标由多个子证据加权聚合，**各证据的贡献之和精确等于总分**。

### 5.1 热稳定性

| 证据 | 权重 | 映射 | 依据 |
| --- | --- | --- | --- |
| IVYWREL 占比 | 0.25 | 0.28→0 分，0.45→100 分 | 公认的嗜热蛋白序列特征 |
| 带电残基占比（DEKR） | 0.15 | 0.16→0，0.32→100 | 表面盐桥网络 |
| 不稳定指数 | 0.15 | 55→0，20→100 | Guruprasad 二肽权重法 |
| 甘氨酸含量 | 0.08 | 最优 0.055 | 过量 Gly 增加构象熵 |
| 脯氨酸含量 | 0.07 | 最优 0.055 | 适度刚性化环区 |
| 结构平均 pLDDT | 0.15 | 60→0，95→100 | 无结构时**剔除并重新归一化** |
| ESM-2 自然度 | 0.15 | −5→0，−1.2→100 | 同上 |

### 5.2 碱稳定性

碱性失活主因是 **Asn/Gln 脱酰胺**与**二硫键重排**，因此以这两类基序密度为核心：

* 脱酰胺敏感基序加权密度（权重 0.40）：`Asn-Gly`(1.00) > `Asn-Ser`(0.72) >
  `Asn-His`(0.65) > `Asn-Thr`(0.62) > `Asn-Asp`(0.55) > `Asn-Ala`(0.45)，
  Gln 系列约低 3 倍；
* Asn 占比（0.18）、Gln 占比（0.12）；
* 潜在二硫键数（Cys 对数，0.30）。

### 5.3 酸稳定性

* **Asp-Pro 酸敏感肽键密度**（0.32）：pH 2-3 下数小时即可断裂，是低 pH
  洗脱/酸沉步骤的主要断链风险；
* 酸性残基占比（0.20）：低 pH 下质子化、盐桥瓦解；
* 芳香族占比（0.20）：酸稳定蛋白（如胃蛋白酶）芳香族含量偏高；
* 脱酰胺基序密度（0.16）：低 pH 同样促进 Asn-Gly 脱酰胺；
* 疏水核心埋藏程度（0.12，需结构）。

### 5.4 溶解性

依据重组表达可溶性的已发表序列决定因素：

| 证据 | 权重 |
| --- | --- |
| 转角形成残基占比（STNQGP） | 0.24 |
| 净电荷密度（\|净电荷\|/长度，pH 7） | 0.20 |
| GRAVY 疏水指数 | 0.16 |
| 最长连续疏水片段（滑窗均值 > 1.6） | 0.16 |
| 半胱氨酸占比 | 0.14 |
| 疏水片段数量 | 0.10 |

### 5.5 聚集倾向

**逐残基滑窗打分**（窗口 7）：

```
score(i) = 100 × hydro_norm × beta_norm
  hydro_norm = clip((mean_KyteDoolittle + 0.5) / 4.0, 0, 1)
  beta_norm  = clip((mean_ChouFasman_beta − 0.70) / 0.80, 0, 1)
```

**为什么是乘积**：只有同时具备"疏水 + 高 β 倾向"的片段才是真正的聚集热点；
单纯疏水但富含 Gly/Pro（柔性）的区域不应被判为热点。

聚合为总分：峰值（0.30）、热点残基数（0.22）、热点区段数（0.16）、
芳香族占比（0.12）、低复杂度占比（0.10）、疏水核心暴露（0.10，需结构）。
阈值 `HOTSPOT_THRESHOLD = 62`。

### 5.6 表达量趋势

> **诚实的边界说明**：只有氨基酸序列时**无法计算真正的 CAI**（需要 DNA 密码子）。
> 平台明确区分两种模式，并对蛋白序列模式给出可从序列严格推导的代理特征。

**蛋白序列模式**（当前）：

| 证据 | 权重 | 说明 |
| --- | --- | --- |
| 最优密码子可用度 | 0.26 | 每种氨基酸在宿主中最常用密码子频率的均值 |
| 宿主氨基酸使用偏好距离 | 0.20 | 目标蛋白组成与宿主蛋白组的卡方距离 |
| N 端规则（Met 后第二位） | 0.16 | A/C/G/P/S/T/V 稳定；R/K/F/L/W/Y/I/D/E/N/Q 易降解 |
| N 端 18 残基平均疏水性 | 0.14 | 信号肽/膜靶向风险 |
| 核糖体停滞敏感基序 | 0.12 | `RR`(1.0) `RPR`(0.7) `PPP`(0.8) `GGG`(0.6) `KKK`(0.5)，E. coli 中经实验证实 |

### 5.7 修饰位点风险

覆盖 8 类修饰的共识基序扫描：脱酰胺、异构化（Asp-Gly 等）、氧化
（Met 1.0 / Cys 0.85 / Trp 0.6 / His 0.5 / Tyr 0.35）、N-糖基化（N-X-S/T，X≠P）、
O-糖基化（Ser/Thr 富集区）、胶原羟脯氨酸位点（Gly-X-Y 的 Y 位 Pro）、
N 端焦谷氨酸（N 端 Gln/Glu）、赖氨酸糖化。

### 5.8 免疫原性风险

> **定位必须明确**：本模块是**筛查级启发式**，不是 NetMHCIIpan / IEDB 的替代品。

基于 MHC 结合槽的**锚定残基偏好**这一公认结构原理：

* MHC-II：9 聚体核心，P1（权重 0.35，偏好大疏水/芳香）、P4（0.20）、P6（0.20）、P9（0.25）；
* MHC-I：9 聚体，P2 与 P9 锚点；
* 两亲性螺旋倾向（Eisenberg 疏水矩，窗口 11，角 100°）。

打分是各锚点偏好的加权和，用于**同一平台内候选之间的相对排序**，
**不能解释为绝对结合亲和力（IC50）**。若需法规申报级数据，建议接入
NetMHCIIpan（`predict_mhc2_binders` 已预留替换点）。

### 5.9 宿主蛋白酶抗性

以大肠杆菌胞内主要蛋白酶的识别偏好为核心：OmpT/Tsp（碱性残基对 `[RK][RK]`，
权重 0.34）、Lon/ClpP（连续疏水三残基，0.28）、HslUV（0.20），
外加工具酶识别位点唯一性检查（0.18）。

## 六、突变设计层

### 6.1 扫描范围规划

1. 排除序列末端（默认各 1 位，避免干扰翻译起始/终止）；
2. 排除规则包保护位点；
3. 遵守用户给定区段；
4. 位点数超过上限时，用**未掩码对数概率**做一次极廉价预筛（单次前向），
   保留模型约束最弱的位点，并**显式记录降采样行为**（绝不静默丢弃）。

**每个被排除的位点都记录原因**，界面可查——这对实验人员判断结果完整性至关重要。

### 6.2 五维可解释评分

总分公式（`configs/default.yaml` 的 `scoring.dimensions` 定义权重）：

```
total = Σ_{正维度} w_i · s_i / Σw  +  w_risk · (s_risk − 100) / Σw
```

* 正维度：稳定性贡献、活性影响、折叠可行性、宿主表达适配；
* `risk` 以**罚项**计入：安全分 100 不扣分，风险越高扣得越多；
* **各维度贡献之和精确等于总分**，前端瀑布图零残差分解。

### 6.3 组合突变搜索（两阶段）

**为什么需要两阶段**：准确评估组合必须考虑**上位效应**——对每个突变，
要在"其他突变已存在"的背景下重新掩码打分，代价是 `组合数 × 位点数` 次前向。
朴素做法在 15 个候选取 3 个时约需 1365 次前向，耗时以分钟计。

1. **阶段一（廉价）**：单点分数平均 + 上位效应惩罚，估计全部组合。
   惩罚规则：位点间距 < `min_site_distance`（默认 3）时施加惩罚，间距越小越重；
2. **阶段二（精确）**：只对估计排序前 `refine_top_k`（默认 12）的组合做
   上下文依赖的真实重打分。

**组合维度分取各站点的平均值**（而非求和），避免"位点数越多分越高"
导致组合永远优于单点——这是评分体系必须保持的性质。

### 6.4 一致性要求

单点评估与组合精评**必须共用同一个折叠可行性函数**。
早期实现中组合路径跳过了 pLDDT/二级结构修正，导致同一突变
在单点列表中 70.37 分、在组合列表中 76.48 分，破坏可信度。
现已统一，实测同一突变两条路径分差为 **0.00**。

## 七、实验回流与模型迭代层

### 7.1 预测-实测对比的方法学

平台评分是 0-100，实测值有各自量纲（°C、mg/L、U/mg…），**两者不同尺度**，
因此不能直接计算 MAE/RMSE。正确做法：

1. **Spearman ρ（主指标）**：衡量排序一致性，不要求同尺度。
   这是零样本预测器评估的标准做法（ProteinGym 等基准均以 Spearman 为主）。
2. **Pearson r**：线性相关强度。
3. **线性校准后的误差**：拟合 `实测 = a × 评分 + b`，再用校准后的预测计算
   MAE / RMSE / R²，单位与实测一致。

**明确的局限**：校准系数在样本内拟合，样本量小时 R² 会系统性偏高。
样本量 < 4 时平台**不给定量结论**；建议 ≥30 条时改用留一交叉验证。

### 7.2 属性头（PropertyHead）

在 ESM-2 序列嵌入（1280 维）之上训练轻量回归头。

**真正的增量训练**：Ridge 用**充分统计量**累积。
标准化后闭式解为 `w = (XᵀX + αI)⁻¹ Xᵀy`，只需保存 `A = XᵀX` 与 `b = Xᵀy`，
新数据到来时 `A += X_newᵀX_new`、`b += X_newᵀy_new` 再重新求解。
**结果与全量重训在数值上等价**，代价从 O(n·d²) 降为 O(n_new·d²)。

对于非线性的 `hgb`（HistGradientBoosting）没有闭式增量解，
`partial_fit` 会退化为全量重训，并在返回中**明确标注**。

**评估缓冲区**：增量训练必须在跨越新旧数据的评估集上计算指标。
若只用新增的 2 条样本算 R²，会得到 −251 这类毫无意义且严重误导的数字
（本项目开发中实测踩过）。平台维护一个上限 500 条的评估缓冲区。

**增量水位线**：用"已消费的最大 `ExperimentRecord.id`"而不是 `created_at`。
SQLite 的 `CURRENT_TIMESTAMP` 只有秒级精度，同一秒内产生的记录用时间比较会被漏判。

## 八、领域规则包

### 8.1 胶原蛋白

* **保护**：全部处于 Gly-X-Y 相位的 Gly。Gly 是唯一能把侧链塞入螺旋轴心的
  残基，任何 Gly→X 都会直接破坏三股螺旋；
* **Y 位（相位 2）引入 Pro**：可被脯氨酰-4-羟化酶转化为羟脯氨酸，
  通过水桥网络提升 Tm 10 °C 以上——最直接的稳定性提升路径（因子 1.00）；
* **Y 位引入 Lys**：为赖氨酰氧化酶介导的共价交联提供位点（0.95）；
* **X/Y 位引入带电残基**：链间离子型相互作用（0.78-0.85）；
* **X/Y 位引入 F/W/Y**：大侧链与相邻链空间冲突，劝退（0.18-0.25）。

相位判定基于 `gly_xy_phase()`，**不依赖任何绝对编号**，因此对全长 COL1A1、
重组胶原片段、模型肽都适用。

### 8.2 重组蛋白酶（枯草杆菌蛋白酶家族）

**活性位点识别用序列模体，不用硬编码编号**（前体与成熟酶编号相差 107 位）：

| 模体 | 偏移 | 角色 | BPN' 编号 |
| --- | --- | --- | --- |
| `DSG` | 0 | 催化 Asp | Asp32 |
| `HGTH` | 0 | 催化 His | His64 |
| `GTSM` | 2 | 催化 Ser | Ser221 |
| `GNEGT` | 0 | 氧负离子洞 Asn | 催化 Ser 上游 67 位 |

模体经 UniProt P00782 实测校准，**每个模体在该序列中唯一出现**
（早期误用 `DGN` 与 `NNS`：前者在序列中根本不存在，后者出现两次导致过度保护）。

**相对间距自校验**（与编号体系无关的不变量）：
Ser−His = 157、Ser−Asp = 189、Ser−Asn ≈ 66-67。
实测四项全部通过，这是识别正确性的**独立交叉验证**。

**前导肽保护**：默认保护催化 Ser 之前的所有残基（信号肽 + propeptide，
成熟过程中被自切去除）。在这些位点推荐突变对成熟酶毫无意义。

**改造方向偏好**：嗜热同源物富集 E/K/R/Y/F/W/P，而 G/N/Q/C/M 偏少。

### 8.3 蛋白 A

* **串联重复检测**：枚举结构域长度（40-75 aa）与相位偏移，
  计算片段间平均一致性，取最优方案。蛋白 A 的 5 个 Ig 结合域一致性远高于随机；
* **跨重复保守位点**（一致性 ≥ 80%）自动保护：这些是框架与 Fc 结合界面核心，
  比硬编码编号稳健得多（不同菌株与构建体编号差异很大）；
* **耐碱改造**：碱性失活主因是 Asn 脱酰胺（尤其 Asn-Gly）。
  业界成熟策略是把关键 Asn 替换为 Gln/Asp/Thr/Ser/Ala——
  既消除脱酰胺位点，又保留氢键能力（因子 0.80-0.92）；
* **引入新的 Asn/Gln 严格劝退**（因子 0.15）：与耐碱目标直接冲突。

## 九、适用边界与已知局限

| 局限 | 说明 | 缓解措施 |
| --- | --- | --- |
| **评分是相对排序指标** | 0-100 分不是 ΔΔG（kcal/mol） | 报告中反复标注；`foldability.delta_g_proxy()` 明确标注"未校准" |
| **ΔlogP 未做 kcal/mol 校准** | 与实验 ΔΔG 单调相关，但需回归校准 | 企业数据 ≥30 条后可用属性头做正式校准 |
| **结构预测依赖外网** | ESM Atlas 是外部服务 | 磁盘缓存；可部署本地 ESMFold |
| **分片结构跨片取向未建模** | 超长序列的整体构象不可信 | 显式标注片段边界与局限 |
| **免疫原性是筛查级** | 非绝对亲和力预测 | 明确标注；预留 NetMHCIIpan 替换点 |
| **仅蛋白序列时无法计算 CAI** | 需要 DNA 密码子 | 明确区分两种模式，给出可严格推导的代理特征 |
| **性质预测多为启发式** | 精度在实测数据校准前为趋势级 | 每项标注算法来源与置信度；支持增量训练提升 |
| **无实验数据时模型无泛化保证** | 零样本打分的绝对精度有限 | 相对排序可靠；建议以 Top-N 筛选而非单点决策 |

## 十、算法参数调节入口

所有关键参数都在 `configs/default.yaml`，**无需改代码**：

* `scoring.dimensions.*.weight`：五维评分权重；
* `design.zero_shot.delta_worst/delta_best`：ΔlogP 归一化锚点；
* `design.foldability/activity/risk.*`：各维度的子权重与阈值；
* `combination.*`：组合搜索的位点数、束宽、上位惩罚；
* `scan.*`：扫描位点上限、末端排除数；
* `rulepacks.*`：三类规则包的启用项与偏好残基集合；
* `risk_thresholds.*`：风险等级阈值。

修改后重启服务即可生效。
