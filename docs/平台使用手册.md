# AI 辅助蛋白设计平台 · 使用手册

面向企业研发与生物技术团队，**不需要 AI 背景**即可完成从序列输入到实验方案导出的全流程。

---

## 一、五分钟上手

1. 打开 `http://<服务器IP>:8848`
2. 在「**序列与结构**」页粘贴目标蛋白序列（或上传 FASTA）
3. 选择蛋白类型（通用蛋白 / 胶原蛋白 / 重组蛋白酶 / 蛋白 A）
4. 点「**预测三维结构**」，查看按置信度着色的结构
5. 到「**性质报告**」页点「**开始预测**」，获得 9 项性质评分与风险位点
6. 到「**突变设计**」页点「**开始设计**」，获得按综合分排序的突变方案
7. 导出候选方案（CSV / Markdown）交给实验团队
8. 实验完成后到「**实验与迭代**」页导入实测数据，平台会自动评估预测可靠性

## 二、五个页面的分工

### 2.1 工作台（`index.html`）

平台的总览与作业中心。

| 区域 | 用途 |
| --- | --- |
| 概览指标 | 项目数、已分析序列、设计批次、突变候选、实验记录、模型版本 |
| 作业队列 | 实时查看正在运行与最近完成的作业；失败作业会显示原因 |
| 平台状态 | 结构预测通道可用性、蛋白语言模型状态、GPU 与缓存占用 |
| 分析流程 | 四步流程的快捷入口 |
| 已保存的分析结果 | 历史设计批次与性质预测，点击可直接跳转 |

**关键提示**：结构预测是**在线服务**，长序列耗时可达数分钟。提交后不必守在页面，
作业在后台执行，随时回到工作台即可看到进度。

### 2.2 序列与结构（`structure.html`）

#### 输入与校验

* 直接粘贴序列，或粘贴带 `>` 头的 FASTA 内容；
* 也支持拖拽 FASTA 文件到输入框；
* 输入时**实时校验**，右侧显示：
  * 长度与序列指纹；
  * 非法字符（会明确报错，不会静默丢弃）；
  * 歧义残基位置（B/Z/J/X/U/O）；
  * 氨基酸组成图表与分组占比。

> **歧义残基的处理规则**：性质预测可以继续（会提示置信度下降），
> 但**突变设计会拒绝**——蛋白语言模型只接受 20 种标准氨基酸。
> 严格模式下，数字、`*`、`-` 这类误粘贴字符会直接报错而不是被悄悄清理。

#### 蛋白类型

选择决定启用哪个**规则包**，直接影响保护位点与推荐方向：

| 类型 | 规则包行为 |
| --- | --- |
| 通用蛋白 | 表面优先；避免新增游离半胱氨酸；避免在螺旋中引入脯氨酸 |
| 胶原蛋白 | 保护三股螺旋 Gly 位；优先推荐 Y 位羟脯氨酸与交联位点 |
| 重组蛋白酶 | 按序列模体保护催化三联体与氧负离子洞；按嗜热偏好推荐 |
| 蛋白 A | 检测串联 Ig 结合域；保护跨重复保守位点；优先消除脱酰胺位点 |

#### 三维结构

* 按 **pLDDT** 热力着色（配色与 AlphaFold 官方一致，便于与文献对照）：
  * 深蓝 ≥90（极高）｜浅蓝 70-90（可信）｜黄 50-70（较低）｜橙 <50（极低）
* 支持卡通 / 棒状 / 线框 / 表面四种显示模式；
* 结构指标面板显示平均置信度、置信度分级占比、二级结构组成、
  回旋半径、平均相对 SASA、疏水核心暴露比例、柔性区域占比。

#### 结构来源与局限（**务必阅读**）

| 来源 | 含义 |
| --- | --- |
| `esmatlas` | 在线 ESMFold 真实预测 |
| `local_esmfold` | 本地 ESMFold 真实预测（离线部署） |
| `stub` | **离线占位结构，无生物学意义**，用于界面演示 |

* 序列超过约 400 残基时会**自动分片折叠**，界面会显示片段数与边界；
  **片段之间的相对取向未经建模**，片段内部结构有效，整体构象不可信；
* 平台**绝不会静默截断**，所有降级、分片、缓存命中都会显式标注。

### 2.3 性质报告（`property.html`）

输出 **9 项** 0-100 的评分（**分数越高越好**，风险类为"安全性得分"）：

| 指标 | 含义 | 主要算法来源 |
| --- | --- | --- |
| 热稳定性 | 抗热变性能力 | IVYWREL 特征 + 带电残基占比 + 不稳定指数 + pLDDT + ESM-2 自然度 |
| 碱稳定性 | 抗碱性失活能力 | 脱酰胺敏感基序加权密度 + Asn/Gln 占比 + 二硫键负荷 |
| 酸稳定性 | 抗酸水解与酸变性 | Asp-Pro 酸敏感键 + 酸性残基占比 + 芳香族占比 |
| 溶解性 | 可溶表达倾向 | 转角残基占比 + 净电荷密度 + GRAVY + 最长疏水片段 + Cys |
| 聚集风险 | 聚集倾向（安全性） | 逐残基滑窗（疏水性×β倾向）+ 热点区段 + 芳香族/低复杂度 |
| 表达量趋势 | 宿主表达潜力 | 宿主密码子使用偏好 + N 端规则 + N 端疏水段 + 停滞基序 |
| 修饰位点风险 | PTM 异质性（安全性） | 脱酰胺/异构化/氧化/糖基化/羟化/焦谷氨酸/糖化基序扫描 |
| 免疫原性风险 | T 细胞表位（安全性） | MHC-II 锚点偏好 + MHC-I 锚点 + 两亲性疏水矩 |
| 宿主蛋白酶抗性 | 抗降解能力 | OmpT/Tsp、Lon/ClpP、HslUV 识别偏好 |

**每个指标都必须展开看依据**：点击折叠面板可看到逐条证据
（特征值、对总分的贡献、中文依据说明）与算法来源。

#### 位点轨道图

横向蛋白示意图上按类型分色叠加所有风险位点：
脱酰胺（黄）、氧化（红）、异构化（紫）、酶切位点（蓝）、羟化（紫罗兰）、
聚集热点（粉）、翻译停滞（灰）、疏水片段（橙）、酸敏感键（黄绿）、半胱氨酸（青）。
下方还有一条聚集倾向的连续轨道（青→红渐变）。

鼠标悬停在标记上可看到具体位置、基序与说明。

#### 宿主表达体系

不同宿主的密码子偏好差异显著，选择正确的宿主会改变「表达量趋势」的评分与依据。
密码子表来自 **Kazusa 官方数据库**，界面上会显示参考集规模
（样本量小的表平台会提示"解释需谨慎"）。

### 2.4 突变设计（`design.html`）

#### 三种设计模式

| 模式 | 适用场景 | 代价 |
| --- | --- | --- |
| 单点突变 | 逐步验证，每次改一个位点 | 快（数百位点约十几秒） |
| 多点组合 | 需要叠加多个改造效果 | 慢（含束搜索与上位效应精评） |
| 局部序列优化 | 只想微调、不想大改 | 快（仅评估保守替换） |

#### 候选排序表

* 列可点击排序（总分与五个维度）；
* 支持按最低分过滤；
* 带告警的候选行有淡黄底色，告警数量显示在最后一列；
* 点击任意行 → 右侧「可解释评分卡」展开。

#### 可解释评分卡（核心）

选中候选后展示：

1. **瀑布式分数分解**：五个维度各自对总分的贡献，**各项之和精确等于总分**，
   不存在无法归因的残差；
2. **逐维度中文依据**：例如"埋藏位点（相对SASA=0.12）体积变化 68 Å³，可能造成核心堆积缺陷"；
3. **模型原始信号**（可展开）：ΔlogP、野生型日志概率、结构上下文、体积/电荷变化。

五个维度的含义：

| 维度 | 含义 |
| --- | --- |
| 稳定性贡献 | ESM-2 掩码边缘似然比（模型是否"认可"该替换） |
| 活性影响 | 模型保守性 + 与功能位点距离 + 规则包偏好 |
| 折叠可行性 | 野生型 pLDDT 先验 + 模型耐受度 + 二级结构上下文 |
| 宿主表达适配 | 停滞基序、含硫残基、N 端规则的变化 |
| 新增风险位点 | 是否引入新的脱酰胺/氧化/酶切/聚集位点（**以罚项计入总分**） |

#### 结构热点联动

选中候选时，右侧 3D 视图会**高亮该候选的全部突变位点**并自动聚焦。
这让你在提交实验前就能确认"这个位点到底在结构上处于什么位置"。

#### 扫描透明度（**为什么某些位点没被推荐**）

平台明确列出：

* 参与扫描的位点数与候选总数；
* **受保护位点**（来自规则包）及其保护原因；
* 被排除位点及排除原因分布（末端、超出区段、受保护）。

没有位点会被静默丢弃。

#### 导出

* **CSV**：适合直接给实验团队排期（含逐维度分数、告警、评分说明）；
* **Markdown 报告**：含逐条候选的完整维度依据，适合作为设计说明归档。

### 2.5 实验与迭代（`experiment.html`）

#### 下载模板

提供 `xlsx` 与 `csv` 两种模板，包含列定义说明与示例行。

标准列：`样品 / 突变 / 属性 / 实测值 / 单位 / 条件 / 重复 / 操作人 / 日期 / 备注`

**列名支持中英文别名自动识别**，例如「突变体 / mutant / variant / 突变位点」
都会被识别为 `mutation`；属性名「热稳定性 / Tm / thermostability」归一到同一指标键。

#### 导入流程（建议两步）

1. **预演**：保持「仅校验」勾选 → 选文件 → 查看列映射、异常行、数据预览；
2. **正式导入**：取消「仅校验」→ 重新选择文件 → 数据入库。

平台会：
* **逐行校验并定位错误**（行号 + 字段 + 原因），绝不静默丢弃；
* 自动去重（同一 `序列+突变+属性+条件+重复` 的记录不会重复入库）；
* 无法识别的属性名会原样保留并提示"不参与对比"。

#### 预测-实测对比

选择序列 → 点「开始对比」。平台会**为每个突变体重算预测值**，与实测值配对后输出：

| 指标 | 说明 |
| --- | --- |
| **Spearman ρ** | **主指标**。平台评分是 0-100，实测值有各自量纲，两者不同尺度，因此以秩相关衡量排序一致性（这也是零样本预测器的标准评估方式） |
| Pearson r | 线性相关强度 |
| 校准后 MAE / RMSE / R² | 先拟合 `实测 ≈ a × 评分 + b`，再用校准后的预测计算误差，单位与实测一致 |

**重要局限**：校准系数在样本内拟合，样本量小时 R² 会系统性偏高。
样本量 < 4 时平台**不给定量结论**，只提示"仅作参考"。

#### 模型迭代

1. **全量训练**：在 ESM-2 序列嵌入之上训练轻量属性头（Ridge / 梯度提升）；
2. **增量训练**：只消费上次训练之后新增的实验记录。
   Ridge 用充分统计量累积，**增量结果与全量重训数值等价**；
3. **版本回滚**：每次训练生成新版本并自动激活，历史版本保留，可一键切回。

平台会诚实标注评估指标的口径：

* 样本量 ≥ 15 时按 8:2 划分留出集，指标来自**未参与训练**的数据；
* 样本量 < 15 时**不划分留出集**，只报告交叉验证指标，并明确说明
  "留出集评估波动极大"。

## 三、推荐的实验工作流

```
① 序列与结构 ──→ 确认序列正确、结构可信、蛋白类型选对
        ↓
② 性质报告 ──→ 找到最弱的 2-3 项指标（这就是改造方向）
        ↓
③ 突变设计 ──→ 按最弱指标筛选候选；优先选"高分 + 零告警"
        ↓
        ├─ 单点验证：导出 Top 10-20 条，实验验证
        ├─ 组合方案：在验证有效的位点基础上用组合模式叠加
        ↓
④ 实验与迭代 ──→ 录入实测数据 → 看 Spearman → 决定是否继续用该指标
        ↓
  数据积累 ≥15 条 ──→ 触发训练，后续预测会更贴合本企业的体系
```

### 结果解读的三个要点

1. **关注排序，而非绝对值**：平台评分是相对排序指标（0-100），
   用于在众多候选中挑出前几名，**不是** ΔΔG（kcal/mol）这类绝对物理量。
   平台在报告中明确标注了这一点。
2. **优先看"零告警"候选**：带告警的候选不是不能用，而是需要额外实验确认
   （例如引入的游离半胱氨酸是否影响折叠）。
3. **善用"扫描透明度"**：如果你的目标位点没出现在推荐里，
   先看它是否被规则包保护（例如三股螺旋的 Gly 位、催化三联体）——
   这些位点被保护是有明确生物学理由的。

## 四、术语速查

| 术语 | 含义 |
| --- | --- |
| **pLDDT** | 结构预测的逐残基置信度（0-100），不是准确度本身 |
| **ΔlogP** | ESM-2 掩码边缘似然比，零样本突变效应代理指标，越接近 0 越"自然" |
| **SASA** | 溶剂可及表面积，用于判断残基是埋藏还是暴露 |
| **GRAVY** | 序列平均疏水性，正值偏疏水、负值偏亲水 |
| **不稳定指数** | Guruprasad 指标，>40 通常判为体外不稳定 |
| **CAI** | 密码子适应指数，**只有基因序列才能算**；平台在仅有蛋白序列时明确说明无法计算 |
| **上位效应** | 多个突变相互影响、效应不能简单相加 |
| **Spearman ρ** | 秩相关系数，衡量排序一致性 |
| **Gly-X-Y** | 胶原三股螺旋的必需重复周期，Gly 位于每三个残基的第一位 |
