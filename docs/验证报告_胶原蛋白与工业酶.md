# 标准化测试案例验证报告

对象：胶原蛋白（人 I 型胶原 α1 链）与工业酶（枯草杆菌蛋白酶 BPN'）
版本 0.1.0 ｜ 验证日期 2026-09-15

---

## 一、验证目的与方法

### 1.1 目的

依据需求文档"针对胶原蛋白和至少一种工业酶的标准化测试案例及验证报告"，
本报告对平台在两个**真实蛋白**上的表现做定量验证，重点回答三个问题：

1. 平台能否正确处理这两类蛋白的**领域特殊约束**（三股螺旋 Gly-X-Y 周期、
   丝氨酸蛋白酶催化三联体）？
2. 平台的推荐是否**不违背领域知识**（例如不推荐改催化残基、不推荐改必需 Gly 位）？
3. 平台在**超长序列、外部服务失败**等边界条件下是否行为可预期？

### 1.2 方法

| 环节 | 做法 |
| --- | --- |
| 序列来源 | UniProt 官方 REST 拉取，**不使用任何人工编造的序列** |
| 结构预测 | ESM Atlas 在线服务；超长序列自动分片 |
| 突变设计 | 全位点 × 19 氨基酸零样本扫描（ESM-2 掩码边缘似然比） |
| 一致性判定 | 由脚本自动断言，**任何不符合领域知识的推荐都会使脚本返回非零退出码** |

可复现命令：

```bash
python scripts/fetch_seed_sequences.py          # 拉取标准序列
python scripts/run_case_industrial_enzyme.py    # 工业酶案例
python scripts/run_case_protein_a.py            # 蛋白 A 案例
python scripts/run_case_collagen.py             # 胶原蛋白案例
```

结构化结果：`data/validation/case_*.json`

## 四、案例三：蛋白 A（补充验证）

需求文档点名了蛋白 A 的"亲和力、耐碱性提升"需求，因此额外补充该案例。

| 项目 | 值 |
| --- | --- |
| UniProt 条目 | P38507 `SPA_STAAU`（Staphylococcus aureus） |
| 序列长度 | 508 aa |
| 结构 | ESM Atlas 返回 504 → 降级 stub（同胶原案例） |

### 4.1 串联结构域检测

检测到 **7 个重复单元**（每个约 58 aa，单元间平均一致性 30%），
自动保护 **14 个跨重复保守位点**（框架 + Fc 结合界面）。

> 说明：蛋白 A 的 Ig 结合域（E/D/A/B/C）一致性较高，而 X 区也存在低一致性重复，
> 因此检出 7 个单元属于预期范围内的结果。保护策略采用"跨重复保守"而非
> 硬编码编号，对不同菌株与构建体都适用。

### 4.2 耐碱性改造验证

| 指标 | 值 |
| --- | --- |
| **改造前碱稳定性基线** | **31.8 / 100**（偏低） |
| Asn-Gly 高敏感脱酰胺基序 | 7 个 |
| Asn / Gln 总数 | 60 / 37 |
| Asn → Gln/Asp/Glu/Thr/Ser/Ala 推荐数 | 288 条 |

**这是最有价值的一致性验证**：平台独立给出的"碱稳定性偏低"结论，
与天然蛋白 A 在 0.1 M NaOH 清洗条件下失活的已知事实一致；
推荐方向也完全符合业界成熟的耐碱改造策略（消除 Asn 脱酰胺位点）。

### 4.3 一致性校验

| 校验项 | 结果 |
| --- | --- |
| 检测到串联 Ig 结合结构域 | ✓ 7 个单元 |
| 保护位点来自跨重复保守分析 | ✓ 14 个 |
| 推荐不触及保守位点 | ✓ 违规 0 条 |
| 存在 Asn 耐碱改造建议 | ✓ 288 条 |
| **Top 30 推荐中无引入新 Asn/Gln 的方案** | ✓ Top-N 中 0 条（全量 708 条已降权） |

**脚本退出码 0（全部通过）**

> **关于第 5 项的判定逻辑**：规则包对"引入新 Asn/Gln"施加的是**降权**
> （因子 0.15）而非剔除，因此这类候选仍存在于全量候选中（708 条），
> 但**不应出现在推荐列表里**。这一项校验的正是"惩罚是否真正生效"。

### 4.4 观察到的改进

| 阶段 | Top 候选 | 问题 |
| --- | --- | --- |
| 加入结构域边界保护前 | N5E、N5Q、N35E、N35Q… | 落在**信号肽内**（第 5、35 位） |
| 加入结构域边界保护后 | N157Q、N424A、N469A、N481Q… | 落在 Ig 结合结构域内（结构域起点为第 59 位） |

> **技术说明**：蛋白 A 的信号肽属于革兰氏阳性菌类型，其疏水核心不典型，
> 通用信号肽启发式会漏判。因此本案例改用**结构域边界**判定——
> 首个 Ig 结合结构域之前的序列不进入最终产品。这比信号肽预测更可靠。

## 五、跨案例的共性发现

### 5.1 用"会被切除的区段"做改造是系统性陷阱

三个案例**都**出现了同一类问题：平台的 Top 候选最初落在信号肽、前导肽或前肽区，
而这些区段在成熟过程中被切除，对其推荐突变对最终产品毫无意义。

| 蛋白 | 被切除区段 | 判定依据 |
| --- | --- | --- |
| 枯草杆菌蛋白酶 | 信号肽 + propeptide（1-107） | 催化 Ser 位置推算（成熟酶偏移 107） |
| 胶原蛋白 | 信号肽 + N-前肽（1-178） | 首个持续 Gly-X-Y 重复块（≥20 三联体） |
| 蛋白 A | 信号肽 + 前导区（1-58） | 首个串联 Ig 结合结构域起点 |

**通用信号肽启发式**（N 端疏水核心）对前两者有效，对蛋白 A 漏判——
因此平台采用"**通用启发式 + 各蛋白类型的结构域边界**"双重判定，
任一命中即保护，并在扫描计划中**逐位点写明保护原因**。

### 5.2 外部服务不可靠是常态

| 现象 | 出现次数 | 平台行为 |
| --- | --- | --- |
| ESM Atlas 返回 504 | 2 次（508 aa 与 337 aa 片段） | 自动降级到 stub，写入 `degradation_reason`，界面与报告显式标注 |
| 382 aa 单次折叠耗时 183 s | 1 次 | 结果落盘缓存，重复分析 0 s |

平台**从不静默失败**：降级原因、分片边界、缓存命中状态都会出现在接口响应中。

## 六、验证过程中发现并修复的缺陷

本报告的验证过程本身也用于发现缺陷。以下问题**由验证/测试暴露并已修复**：

| # | 缺陷 | 影响 | 修复 |
| --- | --- | --- | --- |
| 1 | `get_db` 依赖只 `flush` 不 `commit` | 所有直接改库的路由（新增/删除序列与项目、录入实验记录、激活模型版本）**静默丢数据**——接口返回 200 但数据没落库 | 在请求正常结束时 `commit`，异常时 `rollback` |
| 2 | `top_n` 从未用于截断结果 | 请求 `top_n=10` 却返回 1197 条候选；全长胶原蛋白扫描 2 万+ 候选会把作业结果 JSON 撑爆数据库 | `DesignResult` 保留全量候选供组合搜索，对外序列化时按 `top_n` 截断 |
| 3 | pLDDT 量纲未归一化 | ESM Atlas 返回 0-1 分数，被当作"0.93 分"的荒谬置信度 | 按"最大值 ≤1.5 判定为分数制"自动×100 |
| 4 | DSSP-lite 氢键方向写反 | α-螺旋被全部判为无规卷曲 | 按 DSSP 定义修正为 CO(i)···HN(i+i+n) |
| 5 | 序列自然度用了未掩码 logits | 双向模型"抄答案"，天然蛋白也得到 −0.157 的失真值 | 改用掩码伪对数似然（实测 −1.08） |
| 6 | 活性位点模体 `DGN`/`NNS` 错误 | 催化 Asp 完全漏检，氧负离子洞过度保护 | 实测校准为 `DSG`/`HGTH`/`GTSM`/`GNEGT`，并加入相对间距自校验 |
| 7 | 单点与组合两条评分路径不一致 | 同一突变在两处得分不同（70.37 vs 76.48） | 共用同一折叠可行性函数，实测分差降为 **0.00** |
| 8 | 增量训练时间窗口用秒级时间戳 | 同一秒内产生的记录被判定为"无新增"，增量训练永不触发 | 改用 `last_record_id` 水位线 |
| 9 | 增量训练指标只用新样本计算 | 得到 R² = −251 这类严重误导的数字 | 维护评估缓冲区，指标覆盖新旧全部样本 |
| 10 | 测试中手写"类枯草杆菌蛋白酶"序列 | 与真实序列不符（His 间距 153 vs 157），活性位点验证失效 | 测试改用真实 UniProt 种子序列；呼应"不编造数据"原则 |

## 七、当前局限（供后续迭代参考）

## 八、结论

1. **领域约束得到正确执行**：三个案例的一致性校验**全部通过**，
   平台未产生任何违背领域知识的推荐（不改催化残基、不改必需 Gly 位、不引入新的脱酰胺风险）。

2. **定性结论与已知事实一致**：
   * 枯草杆菌蛋白酶活性位点识别与文献编号完全吻合（3 项间距交叉验证）；
   * 胶原蛋白 Gly-X-Y 周期识别（363 个三联体）与三股螺旋域边界（179 位）
     与 UniProt 注释一致；
   * 蛋白 A 的碱稳定性被判为偏低（31.8 分），与其实验已知的碱性失活特性一致。

3. **边界条件行为可预期**：超长序列（1464 aa）自动分片并显式标注；
